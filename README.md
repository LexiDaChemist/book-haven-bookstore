# Book Haven Bookstore

## Project Overview

Book Haven Bookstore is a multi-page bookstore website created as part of a Web Development Touchstone project. The website provides an inviting online experience for readers, students, and book lovers by showcasing bookstore products, community engagement, and interactive web features.

## Website Features

* Multi-page website structure
* Homepage introducing the bookstore
* Gallery page featuring bookstore products
* About Us and Contact page with business information and contact form
* Reading Lounge community page
* Newsletter subscription feature
* Shopping cart functionality
* Session storage and local storage implementation
* Responsive and accessible design principles

## Technologies Used

* HTML5
* CSS3
* JavaScript
* sessionStorage
* localStorage

## Website Pages

### Home Page

The homepage introduces Book Haven Bookstore, featured collections, shopping perks, and product categories.

### Gallery Page

The gallery page displays bookstore merchandise and allows users to add products to a shopping cart and review selections.

### About Us / Contact Page

This page provides bookstore information, business hours, and a contact form for customer feedback and custom book requests.

### Reading Lounge Page

The Reading Lounge page encourages reader engagement through reviews, recommendations, and bookstore community features.

## Design Choices

This project uses:

* Color Palette 2
* Typography Option 2
* Book Worm logo
* Font Color 3

The design emphasizes readability, visual balance, and a welcoming bookstore atmosphere.
